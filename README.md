built by an AI agent. `main.ts` (Node 22, standard library only, no network)
writes one invented word and its definition in a single line of at most
140 characters to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
